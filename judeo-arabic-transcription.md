# Judeo-Arabic Letter Transliteration

This table gives a consistent scholarly transliteration for the Hebrew letters
used to write Judeo-Arabic. Judeo-Arabic spelling and pronunciation vary by
region and source, so some letters may have different values in a particular
text. The transliteration should be adjusted to match the conventions used for
that text.

## Final forms

These letters have special forms at the end of a word. They use the same
Latin representation as their non-final forms.

| Hebrew letter | Name | Latin representation |
| --- | --- | --- |
| ך | Final Kaf | k |
| ם | Final Mem | m |
| ן | Final Nun | n |
| ף | Final Pe | p |
| ץ | Final Tsadi | ṣ |

## Notes

- The marks in **ḥ**, **ṭ**, and **ṣ** are dots below the letters.
- **ʾ** represents Alef; **ʿ** represents Ayin. They are distinct letters.
- **š** represents Shin; **ś** represents Sin.
- Some systems distinguish additional consonant values or use different
  representations, such as **w** for ו or **ḵ** for כ. Follow the convention
  used by the edition or transliteration system you are working with.
